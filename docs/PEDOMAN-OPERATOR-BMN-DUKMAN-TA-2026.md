## 1. ISU STRATEGIS PADA PENGELOLAAN BMN

Sebelas isu teridentifikasi. Setiap isu memuat akar masalah yang harus ditangani.

| Kode | Isu | Akar Masalah |
|---|---|---|
| **ISU-01** | Aset tanah | Lahan aset negara belum bersertifikat atas nama Pemerintah → kerawanan sengketa batas dan okupasi pihak luar akibat tidak adanya patok penanda, plang kepemilikan, dan pagar sterilisasi. |
| **ISU-02** | Pemanfaatan rumah negara | Rumah dinas masih dikuasai keluarga pensiunan/ahli waris yang enggan mengosongkan aset dengan Surat Izin Penghunian (SP) yang sebagian besar sudah kedaluwarsa. |
| **ISU-03** | Kantin dan SAE | Pengajuan sewa area kantin koperasi dan pemanfaatan lahan SAE ke DJKN dinilai lambat → menghambat potensi PNBP di Lapas. |
| **ISU-04** | Sarpras keamanan | Pengadaan sarana keamanan baru (CCTV, metal detector, walkie-talkie) belum terbit Surat Keputusan Penetapan Status Penggunaan (SK PSP). |
| **ISU-05** | Perpanjangan senjata api | Buku Pas Senjata Api Dinas dan izin kepemilikan/penggunaan untuk petugas pengamanan (P2U/Rupbasan) sering terlambat diproses polisi → memicu risiko yuridis bagi organisasi. |
| **ISU-06** | Penghapusan senjata api | Senjata api dinas inventaris Lapas rusak berat menumpuk di gudang karena proses penghapusan rumit dan wajib mendapat izin serta rekomendasi teknik Mabes Polri. |
| **ISU-07** | Penghapusan mesin X-Ray | Petugas salah menetapkan status kondisi mesin X-Ray karena tidak memiliki kompetensi khusus → ketidakvalidan data pencatatan BMN. Penilaian kondisi butuh rekomendasi langsung dari tenaga ahli X-Ray. |
| **ISU-08** | Penyusunan RKBMN | Satker Pemasyarakatan tidak ikut menyusun RKBMN → kebutuhan BMN tidak terakomodasi dalam perencanaan dan pengalokasian anggaran. |
| **ISU-09** | Operator BMN | Kurangnya jumlah operator BMN pada Satker → pengelolaan BMN belum optimal. |
| **ISU-10** | Transfer knowledge | Transfer knowledge antar operator belum maksimal → kurangnya ketepatan waktu penyelesaian pengelolaan BMN. |
| **ISU-11** | Indeks Pengelolaan Aset (IPA) | Penyusunan RKBMN tidak sesuai jadwal → memengaruhi optimalisasi penilaian IPA Kementerian Imigrasi dan Pemasyarakatan. |

## 2. TUGAS OPERATOR BMN — PETA KERJA

### KELOMPOK A — ASET, LEGALITAS, DAN PENGAMANAN

#### TUGAS-01 · Sertifikasi dan Pengamanan Aset Tanah
**Merujuk:** ISU-01 · Langkah Kanwil: Mitigasi Risiko Legalitas dan Fisik Aset

**Target output:** 100% tanah UPT terdaftar dan bersertifikat atas nama Pemerintah RI c.q. Kementerian Imigrasi dan Pemasyarakatan; dilengkapi patok tanda batas dan plang kepemilikan melalui kerja sama (MoU) dengan Badan Pertanahan Nasional (BPN).

| No | Kegiatan Operator | Data Dukung yang Diunggah |
|---|---|---|
| 1 | Verifikasi inventaris seluruh tanah UPT: luas, batas, koordinat, status kepemilikan | Daftar tanah (spreadsheet) + peta/bukti |
| 2 | Cek status sertifikasi tiap bidang tanah di BPN/SIMAN | Berkas sertifikat atau bukti proses |
| 3 | Usulkan pemasangan patok tanda batas dan plang kepemilikan | Foto patok dan plang yang terpasang |
| 4 | Pendampingan MoU dengan BPN untuk bidang yang belum bersertifikat | Surat permintaan/koordinasi |

**Indikator:** persen tanah bersertifikat · persen tanah terpasang patok dan plang.

#### TUGAS-02 · Pendataan Ulang Aset Rumah Negara
**Merujuk:** ISU-02 · Langkah Kanwil: Pendataan Ulang Aset Rumah

**Target output:** pendataan ulang pengguna hunian dinas secara tertib; surat teguran berjenjang (I, II, III) terhadap penghuni yang belum mengosongkan, dilanjutkan proses pengosongan secara persuasif dengan pendampingan Aparat Penegak Hukum (APH).

| No | Kegiatan Operator | Data Dukung |
|---|---|---|
| 1 | Pendataan ulang pengguna hunian dinas (nama, dasar hukum, masa berlaku izin) | Formulir pendataan + foto papan nama |
| 2 | Verifikasi masa berlaku SIP/SP; tandai yang kedaluwarsa | Daftar masa berlaku izin |
| 3 | Penyusunan surat teguran berjenjang ke penghuni | Draft/final surat teguran |
| 4 | Dokumentasi proses pengosongan dan pendampingan APH | Berita acara, foto, laporan |

**Indikator:** persen rumah dengan data penghuni mutakhir · jumlah teguran terbitan per jenjang.

#### TUGAS-03 · Penghapusan Senjata Api Rusak Berat
**Merujuk:** ISU-06 · Langkah Kanwil: Monitoring Kepemilikan dan Verifikasi Fisik Senpi

**Target output:** verifikasi fisik senjata api bersama Ditjenpas dan Baintelkam; rekomendasi teknis pemusnahan dari Polri; pemusnahan fisik resmi disaksikan langsung oleh pihak polisi dengan alokasi khusus untuk biaya penghapusan senjata api.

| No | Kegiatan Operator | Data Dukung |
|---|---|---|
| 1 | Daftar inventaris PQ senjata api beserta kondisinya (Baik/Rusak Ringan/Rusak Berat) | Daftar senjata api |
| 2 | Koordinasi tim verifikasi fisik bersama Ditjenpas dan Baintelkam | Undangan/minut/dokumentasi |
| 3 | Pengajuan rekomendasi teknis pemusnahan ke Mabes Polri | Surat pengajuan |
| 4 | Rencana dan pelaksanaan pemusnahan | BAST pemusnahan, foto, dokumentasi |

**Indikator:** jumlah senjata api terverifikasi · jumlah senjata api terpusnahkan.

#### TUGAS-04 · Ketertiban Buku Pas dan Izin Senjata Api

**Target output:** Buku Pas Senjata Api aktif dan izin penggunaan yang valid; **target 0% keterlambatan perpanjangan**; penerapan E-mail dan Calendar Integration sebagai sistem pengingat otomatis untuk masa berlaku izin.

## 4. EVALUASI PELAKSANAAN — PEMBELAJARAN UNTUK OPERATOR

### 4.1 Sisi SDM dan Kompetensi
Keterbatasan kompetensi teknis petugas dalam menentukan kondisi barang bernilai tinggi atau berisiko khusus, seperti mesin X-Ray. Ketiadaan keahlian khusus berpotensi menyebabkan salah penetapan status aset yang berujung pada ketidakvalidan data pencatatan pada aplikasi SAKTI.

**Implikasi operator:** jangan menetapkan kondisi barang berisiko tanpa rekomendasi tenaga ahli.

### 4.2 Sisi Tata Kelola Internal
Aspek pengawasan dan keteraturan administrasi internal. Masalah utama: lemahnya mekanisme pengingat (reminder system) di tingkat Satker maupun Kanwil, sehingga perpanjangan Buku Pas Senjata Api sering mengalami keterlambatan.

**Implikasi operator:** portal SIPADU menyediakan kalender masa berlaku — **wajib diperbarui** agar pengingat otomatis aktif dan tenggat tidak terlewat.

### 4.3 Sisi Kolaborasi Inter-Instansi
Eksekusi program pengelolaan BMN sangat bergantung pada pihak eksternal:
- **BPN** → legalitas tanah
- **Baintelkam Polri** → izin dan pemusnahan senjata api
- **KPKNL** → penetapan status dan sewa aset

> Kanwil dituntut menjadi **jembatan negosiasi dan fasilitator**. Operator Satker wajib menyapkan dokumen lengkap agar proses administrasi antar-instansi berjalan lancar.

## LAMPIRAN — CHECK LIST OPERATOR

Sebelum menutup pekerjaan, pastikan lima hal ini benar:

1. Data sudah **terinput dan ter-disetujui SAKTI**.
2. **Masa berlaku** izin dan sertifikat sudah diperbarui di portal agar pengingat otomatis aktif.
3. Seluruh **data dukung** sudah lengkap pada pengajuan pertama.
4. Tenggat **tidak terlewat**.
5. Untuk barang berisiko, **rekomendasi ahli** sudah dilampirkan.
